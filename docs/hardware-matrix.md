# Hardware matrix

This project has not yet been validated against physical hardware. The table
below distinguishes public series-family hints from hardware verified by this
project.

| Reported series | Public family hint | Controls exposed | Evidence in this project |
|---|---|---|---|
| `R1`–`R3` | Renesa family | Fan, sleep, timer, LED on/off | Not hardware-tested |
| `S1` | Studio+ family | Fan, sleep, timer, LED, brightness | Not hardware-tested |
| `S2` | Renesa Elite family | Fan, sleep, timer, LED, brightness | Tested only by the reference project |
| `I1`–`I4` | Aris family | Fan, sleep, timer, LED, brightness | Not hardware-tested |
| `I5` | Aris Contour family hint | Fan, sleep, timer, LED, brightness, light mode | Not hardware-tested; retail model unconfirmed |
| `M1` | Efficio family hint | Fan, sleep, timer, LED, brightness | Not hardware-tested; not proof of retail model |
| `M2` | Efficio+ family | Fan, sleep, timer, LED | Not hardware-tested |
| `K1` | Gorilla family | Fan, sleep, timer | Not hardware-tested |

Series mappings are provisional. A series code must not be used by itself to
claim the exact retail model or hardware revision. In particular, the Aris
Contour has not been independently verified by this project; `I5` is only a
reported-series family hint.

Before sharing this document, remove full MAC addresses, IP addresses, serial
numbers, Wi-Fi details, and other household identifiers.
